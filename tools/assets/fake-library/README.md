# Fake library scenes

12 base scenes for the DEBUG `store` fake library, which feeds the iPad App Store
screenshots. `tools/build_fake_photo_library.py` turns each scene into a series of
4 similar photos.

- Source: generated with the Codex CLI image generation tool on 2026-11-16. They
  are not photos of real places, people or property.
- Rules in the prompt: no people, faces, hands, readable text, signs, logos,
  brand names, licence plates, house numbers or screens.
- Size: 1448 x 1086, JPEG quality 84.

Before a new scene goes in, check it against the same rules: the screenshots are
public.
