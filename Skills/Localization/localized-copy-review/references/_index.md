# Reference inventory

- `language-review.md`: semantic comparison, fluency, and final review.
- `locale-rules.md`: nine-locale register, Apple terms, paths, and product facts.
- `legal-parity.md`: terms, privacy claims, source law, and disclosure boundaries.
- `marketing-review.md`: natural promotional copy without unsupported promises.

## Optional external methods

This is an original Alike workflow. No third-party skill is copied or required.
The following sources informed the choice of separate review passes:

- [Copy Editing](https://github.com/coreyhaines31/marketingskills/blob/main/skills/copy-editing/SKILL.md):
  focused editing passes for existing marketing text. Use clarity, tone, and
  evidence checks; do not import emotional pressure or new guarantees.
- [Review Contract](https://github.com/anthropics/knowledge-work-plugins/blob/main/legal/skills/review-contract/SKILL.md):
  clause comparison against an explicit playbook. Its commercial-contract
  context does not establish the validity of consumer app terms.
- Installed `ux-writing`: optional depth for interface wording when local
  language and marketing references do not resolve a specific copy problem.

If deeper external guidance is needed, read the selected skill and its required
context first. Do not install a full legal plugin suite to review translations.
Apply the global source-update policy before using managed third-party skills.
